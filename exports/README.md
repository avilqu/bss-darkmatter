# exports

`.dmz` packages (File > Export / File > Import in Dark Matter).

- `*.dmz` here: control pages and workspaces exported from our dome.
- `imported/`: packages received from elsewhere (Sky-Skan tutorials, other presenters) and imported into DM.

Only control-page and workspace exports are kept. Asset-group exports (hundreds of MB to tens
of GB, mostly media) stay on the backup drive. New exports: name them `<Page>-YYYY-MM-DD.dmz`.
