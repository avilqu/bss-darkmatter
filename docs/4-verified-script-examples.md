# Verified Dark Matter script examples

These are working scripts posted on the DSA Dark Matter forum by Sky-Skan staff and Jeff Nee. Use them as patterns. Change the file paths and asset names to match your system before running any of them.

---

## 1. Video plus still image plus caption, with show and hide (Jeff Nee, t=141)
This pattern covers slides, media on a slide, SlideText, scaling in and out, a presenter pause and cleanup.
```
;Show Galileo Sketches
Scene Remove(Galileo-Slide-JPL)
Scene Remove(Galileo-Media-JPL)
Scene Remove(Galileo-Still-JPL)
Scene Remove(Galileo-Label-JPL)
+0.1
Scene Add(Galileo-Slide-JPL, Slide, Scale=0)
Scene Add(Galileo-Media-JPL, Media)
Scene Add(Galileo-Still-JPL, Slide, Scale=0)
Scene Add(Galileo-Label-JPL, SlideText, Scale=0)
+0.1
;Video file goes here:
Scene Galileo-Media-JPL.MediaFile="<ShowPath>\JPL\OOS\Views-Galileo.mp4"
;this puts the video onto the Slide
Scene Galileo-Slide-JPL.Picture="Media:Galileo-Media-JPL"
;This is just a still image:
Scene Galileo-Still-JPL.Picture="<ShowPath>\JPL\OOS\Views-Galileo2.png"
+0.1
Scene Galileo-Label-JPL.Text.String="Sketches of the Sun\nGalileo 1613"
Scene Galileo-Slide-JPL.Slide.TextLock="Height to Width"
Scene Galileo-Still-JPL.Slide.TextLock="Height to Width"
Scene Galileo-Still-JPL.Azimuth=135
Scene Galileo-Still-JPL.Elevation=30
Scene Galileo-Still-JPL.Width=60
Scene Galileo-Slide-JPL.Azimuth=225
Scene Galileo-Slide-JPL.Elevation=30
Scene Galileo-Label-JPL.Azimuth=225
Scene Galileo-Label-JPL.Elevation=30
Scene Galileo-Label-JPL.Text.BackgroundColor=Black
Scene Galileo-Label-JPL.Text.BackgroundVis=0.5
;This double checks that the video will loop:
Scene Galileo-Media-JPL.Looping=Off
+0.1

+0.1
;Play it before you scale it up.
Scene Galileo-Media-JPL.Play()

```

## 11. JavaScript live readout of camera altitude: CreateAssetInstance, a while loop and cleanup (Jeff Nee, t=408)
```
JS Remove(AltitudeDisplay-SkySkan)
+0.1
JS Add(AltitudeDisplay-SkySkan)
+0.1
JS AltitudeDisplay-SkySkan.Execute(@"
var azimuth = 180;
var elevation = 15;
var scale = 0.4;
var color = "yellow";
var altSlideText = DigitalSky.CreateAssetInstance("SlideText", "AltDisplay-SkySkan")
var cameraAsset = DigitalSky.GetAssetInstance("Camera");
var cameraAlt = cameraAsset.GetPropertyInstance("Altitude");
var running = 0;
function formatDistanceString(distance)
{
	var value = distance;
	var unit = "meters";
	if (distance > 9.4607e14) { value /= 9.4607e15; unit = "lightyears"; }
	else if (distance > 149.6e8) { value /= 149.6e9; unit = "astronomical units"; }
	else if (distance > 1000) { value /= 1000; unit = "kilometers"; }
	value = Math.round(value*100)/100;
	return value.toFixed(1) + "\\n" + unit;
}
function Show(az, el, sc, co) {
	if(typeof az === "undefined") az = azimuth;
	if(typeof el === "undefined") el = elevation;
	if(typeof sc === "undefined") sc = scale;
	if(typeof co === "undefined") co = color;
	DigitalSky.SendScript("Scene AltDisplay-SkySkan { Visibility=0 } [0.1]");
	DigitalSky.Wait(0.1);
	DigitalSky.SendScript("Scene AltDisplay-SkySkan { Lens=AllSky Azimuth="+az+" Elevation="+el+" Scale="+sc+" Text.TextColor="+co+" }");
	DigitalSky.SendScript("Scene AltDisplay-SkySkan.Visibility=100 [1]")
	running=1;
	while(running == 1) {
		altSlideText.SetProperty("Text.String", formatDistanceString(cameraAlt.Value),0);
		DigitalSky.Wait(0.1);
	}
}
function CleanUp() {
	running = 0;
	DigitalSky.SendScript("Scene AltDisplay-SkySkan.Visibility=0 [1]")
	DigitalSky.Wait(1);
	DigitalSky.SendScript("Scene Remove(AltDisplay-SkySkan)");
}
@")
+0.1
JS AltitudeDisplay-SkySkan.functionasync(Show)
+1
Control Text="Remove Altitude Display"
Control Pause
JS AltitudeDisplay-SkySkan.functionasync(CleanUp)
+1.1
JS Remove(AltitudeDisplay-SkySkan)
```
(Trimmed slightly from the original: the comma-formatting helper is removed.)

## 12. JavaScript to press Bridge buttons, here a shared Assets Reset (Jeff Nee, t=472)
First give the Bridge's Assets Reset button the reference name `Bridge-AssetsReset`.
```
JS Add(button)
+0.1
JS button.Execute(@"
function dm(script) {
	DigitalSky.SendScript(script);
	DigitalSky.LogMessage(script);
}
function abortButton(name) { dm("Control "+name+".Abort()"); }
function pressButton(name) { dm("Control "+name+".Run()"); }
function text(name, message) { dm("Control "+name+".Text=\""+message+"\""); }
function resetAll() {
	pressButton("Bridge-AssetsReset");
	DigitalSky.Wait(30);
	abortButton("Bridge-AssetsReset");
}
@")
+0.1
Control Text="Reset All?"
Control Pause
Control Text="Resetting..."
JS button.resetAll()
```

## 13. Helpers that make JavaScript renderable: they log an equivalent DM script (Jeff Nee, t=314)
Paste these at the top of any JS engine. The Event Viewer > JavaScript Processor log then contains a timed DM script you can paste into a button for the Playlist Creator.
```
function log(){ var string=Array.prototype.join.call(arguments, ''); DigitalSky.LogMessage(";"+string); }
var console = { log:function() { var message = Array.prototype.join.call(arguments, " "); DigitalSky.LogMessage(";"+message); } };
function wait(num) { DigitalSky.LogMessage("+"+num); DigitalSky.Wait(num); }
function dm(){ var string=Array.prototype.join.call(arguments, ''); DigitalSky.SendScript(string); DigitalSky.LogMessage(string); }
```

## 15. Unsliced 4K fisheye video on the whole dome (Markus Steblei, t=141; Sascha, t=357)
1. Create a Media asset pointing at the video (same path on every PC), with `DSISpec` set to `<ContentPath>\Core\Common\Fisheye.dsi`.
2. Create a Fulldome asset with that media as its source, or point the default layer at it: `Scene Video.Source="Media:MyFilm"`.
3. Drag the media asset onto a control page. This auto-creates a "Play" button.
4. Use H.264 at 4096×4096 and 30 fps (constant frame rate, about 25 Mbps or less). Never use 25 fps. For 60 fps or heavy content, slice the video with SkyVision Renderer 3.
