;=== BSS-VS-VirtualTelescope ===
; Page: BSS-VirtualStargazing   Button: "5 Virtual telescope"   Length: ~150 s
; Chapter 5 (virtual telescope): the life of stars through southern telescope targets. Ring on the
; Carina Nebula, then its photo and a zoom on a Bok globule; ring on the Jewel Box, its photo, then the
; Wishing Well next to it (older open cluster); ring on 47 Tucanae, then its photo.
; Visuals only, no text on the dome (the rings are plain circles).
; Starts from: ground at Mount Cook Village, bright sky, real time (end of chapter 4).
; Ends with:   ground facing south, bright sky, real time.
; Needs the BSS-Lib page loaded (SkyBright, TimeNow, FaceSouth, Carina/JewelBox/WishingWell/47Tuc
; On/Off, Carina/JewelBox/47Tuc RingOn/Off).
;
; Reused from Theater/Adrien through BSS-Lib: NGC3372, NGC4755, NGC3532, NGC104 (photos, still the
; DeepSkyPhoto Asset Manager assets, see BSS-Lib README), Sky settings (bright), Time now, Spin dome.
; The opening runs SkyBright/TimeNow/FaceSouth so the chapter also starts cleanly on its own; after
; chapter 4 they change nothing (all three set absolute values).
; Adrien's "<NGC> label" buttons (circle + name) are replaced by the BSS-Lib rings (no text on the dome).
; UNVERIFIED: Scale on the DeepSkyPhoto photos (Adrien uses it on the ngc..._circle assets of the
; same folder). The zoom adds 3 to Scale (x4 if it starts at 1) and takes it back off once the photo
; is hidden, before BSS-Lib-CarinaOff unloads it.
; UNVERIFIED: the zoom grows around the photo centre. To zoom on a given globule (e.g. near the
; Keyhole, about 10' north-west of the centre), uncomment the Azimuth/Elevation lines in steps 4 and 5
; and set them to -3 x the globule's offset from the centre, in degrees. Find the photo's properties by
; dragging ngc3372 from the Asset Manager into a ScriptPad.
;
; TIMING: estimated from the script text (no recording yet). @m:ss = time since the
; voiceover starts. When the recording exists, set the waits from its timecodes.
; AUDIO PLACEHOLDER: the file below doesn't exist yet. Until it does, Event Viewer
; will report a load error for VirtualTelescopeVO-BSS-VS; the visuals still run.
;
