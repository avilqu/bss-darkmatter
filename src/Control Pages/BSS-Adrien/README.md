# BSS-Adrien

Copy of the dome page `Theater/Adrien`: same buttons, sliders, background panels, labels and
layout. Scripts are unchanged; only the `;` header lines were added. It has its own page GUID and
widget IDs, so it can sit next to the original on the dome. "Toggle" means the button stops at
`Control Pause` and a second press runs the rest.

Reference Names are new (`BSS-Adrien-<Label>`): the original page only had four, noted in those
files' header comments, and nothing on the page calls them.
