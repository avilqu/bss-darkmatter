;=== SNIPPET: Virtual Stargazing ring around a sky object (show-wide method) ===
; Plain circle, no text, fixed to the stars. Use this for every object circled in the show.
; Replace NAME, RA_DEG (RA in hours x 15), DEC_DEG, SIZE and WIDTH.
;
; Pick the image by ring size, so the line looks equally thin (~0.15 deg) on the dome:
;   VS-Ring-S.png  Width 2-4 deg    single stars (Alpha Cen, Beta Cen: 3)
;   VS-Ring-M.png  Width 5-10 deg   small clusters, nebulae, SMC (7)
;   VS-Ring-L.png  Width 10-25 deg  LMC (12), galactic core (20), big asterisms
; Width = object size + a margin, so the ring sits around the object, not on it.
; Images: Assets/BSS/VirtualStargazing/ in the repo -> <ContentPath>\Assets\BSS\VirtualStargazing\
; on DS-Master and every renderer.
; UNVERIFIED: Frame=Sidereal on a Slide, Width in degrees, centring on the object.
;
; --- in the loading block, before the voiceover starts ---
Scene Remove(RingNAME-BSS-VS)
+0.1
Scene Add(RingNAME-BSS-VS, Slide, Visibility=0)
+0.1
Scene RingNAME-BSS-VS.Picture="<ContentPath>\Assets\BSS\VirtualStargazing\VS-Ring-SIZE.png"
Scene RingNAME-BSS-VS.Slide.Blend=Alpha
Scene RingNAME-BSS-VS.Slide.TextLock="Height to Width"
Scene RingNAME-BSS-VS { Frame=Sidereal Azimuth=RA_DEG Elevation=DEC_DEG Width=WIDTH }
+1
;
; --- show (3 s) ---
Scene RingNAME-BSS-VS.Visibility=100 [1:1:1]
;
; --- hide (3 s) ---
Scene RingNAME-BSS-VS.Visibility=0 [1:1:1]
+3
;
; --- at the end of the segment ---
Scene Remove(RingNAME-BSS-VS)
